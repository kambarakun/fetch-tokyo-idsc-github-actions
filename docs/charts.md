# グラフの計算と欠測の扱い

README の「感染動向の可視化」の 6 枚のグラフ (`scripts/generate_charts.py`) が、どの値を描き、どの値を描かないかをまとめる。
方針は「公表された値と、公表値から定義どおりに計算できる集計だけを示し、計算できない値は補わない」である。

## 値の種類

グラフ上では次の 4 つを区別する。

| 種類                    | 例                                            | グラフでの扱い                                            |
| ----------------------- | --------------------------------------------- | --------------------------------------------------------- |
| 公表された 0            | 当週の報告数が 0                              | 0 として描く。順位付けの対象にもなる                      |
| 欠測                    | その週・月のファイルや行・値が無い、`*` / `-` | 点を描かず、前後を線で結ばない                            |
| 比較対象なし            | 比較窓に同週・同月の公表値が 1 年も無い       | 乖離率を算出しない (空白)                                 |
| 比較元 0 による算出不可 | 過去平均が 0 (当期が 0 の場合も含む)          | 乖離率を算出しない (空白)。当期値・比較元・差を注記で示す |

欠測を 0・1・固定値・微小値で置き換えたり、補間・前方補完・隣接週の値で代用したりはしない。
保存済みの `data/` の値はグラフ生成で変更しない。

## 期間軸

- 期間軸は、直近の入力ファイル (週次 52 件、月次 12 件) が覆う期間を暦どおりに連続させたもの。
  週番号は ISO 8601 の週で数える (`data/raw` で第 53 週のファイルがある 2004・2009・2015・2020 年は、ISO で 53 週ある年と一致する)。
- 値の有無ではなくファイルの期間から作るので、最新ファイルの値が全疾患で使えなくても、その期間を最新として軸に残す。
  前の週・月を「最新」と表示しない。ファイルが無い期間も軸に残して空白にする。

## 絶対数グラフ

- 全数報告は報告数 (実数) をそのまま描く。
- 定点報告は「男女合計 ÷ 定点数」の定点当たり値を描く。公表総数と、有限かつ正の定点数がそろう行だけ計算する。
  定点数が空欄・欠落・非数値・0 以下の行は算出不可として描かない。総数 0・定点数が正なら 0 を描く。
- 表示する疾患は、最新の週・月に公表値がある疾患のうち値の大きい上位 5 つ。最新期の公表 0 は対象で、
  最新期が欠測の疾患は 0 とみなさず対象から除く。

## 乖離率グラフ

- 比較元 (季節性ベースライン) は、同じ週番号・月の過去 5 年 (当年を含まない) のうち、公表値がある年だけの平均。
  本リポジトリで計算した集計値で、データ提供元の公表値ではない。欠測の年を 0 として平均に含めない。
- 乖離率は `(当期値 - 比較元) / 比較元 × 100`。比較元が正のときだけ算出する。比較元 10・当期 0 の -100% は有効な値として描く。
- 凡例の「比較元 n年」は、凡例に示した率の期間で平均に使えた年数。5 年分そろわない平均も「5 年平均」とは書かない。
- 第 53 週は当年の公表値をそのまま扱う。比較窓の年に ISO 第 53 週があり、その週の公表値があるときだけ平均に使う。
  第 52 週や翌年第 1 週で代用しない。比較窓に第 53 週がある年が無ければ「過去 5 年に第 53 週がないため比較対象なし」、
  第 53 週がある年の公表値が無ければ「過去 5 年の同週に公表値がないため比較対象なし」と区別して表示する。

### 表示する疾患の選び方

- 最新の週・月に公表値がある疾患だけを順位付けする。
- 順位付けに使う期間は、実数 (定点は男女合計) で実測 5 例以上かつ比較元 1 例以上の期間に限る
  (`DEVIATION_MIN_OBSERVED_CASES` / `DEVIATION_MIN_BASELINE_CASES`)。率を算出できない期間はそもそも順位に入らない。
- 選んだ疾患の線には、順位付けに使わなかった期間の率も描くが、率を算出できない期間は空白のままにする。
- 凡例の値が最新期の率でないときは「最終 YYYY年第N週」のように期間を明示し、最新期に率が無い理由
  (比較元 0 なら当期値・比較元・差) をフッターに書く。

### 何も描けないとき

入力ファイルはあるが描ける値が無い場合 (全期間で比較対象なし・比較元 0、順位付けの条件を満たす率が無い、
最新期に値のある疾患が無い、定点当たり値を 1 つも算出できない) も、理由を中央に書いた図を出力して正常終了する。
古い図が最新の図として残らないようにするため。
3 種類の入力ファイル (定点週次・全数週次・定点月次) がどれも無いときだけ、PNG を書かずに終了コード 2 で失敗する。

## 推定補完との境界

平均・比率・差のように公表値から定義どおり計算できる集計は示す。存在しない週の値、欠測の値、
0 で割る率のように公表値から計算できない値は、統計的に妥当な推定方法があっても補わない。
他機関には第 53 週を前後の週の平均などで補う可視化の例もあるが、本リポジトリでは採用しない。
